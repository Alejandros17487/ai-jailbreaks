# Security Policy

## Scope

This repository contains prompt text and documentation only. It does not ship
executable code, credentials, or user data.

## Reporting

If you find content that exposes private information or could reasonably be used
to harm others, report it privately:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** to start a private advisory.
3. Include the affected file and a short description of the concern.

Please do not post sensitive details in a public issue.
